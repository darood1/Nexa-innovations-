DEPLOYMENT
Upload the CONTENTS of this folder into your web root (e.g. public_html).
Home links to / and other links to /expertise, /contact, etc.
On GitHub Pages, .nojekyll alone does NOT make /about resolve to about.html; configure routing/redirects or use a host supporting rewrite rules.
